# Source Data Overview

This project uses a combination of publicly available higher-education datasets to simulate a realistic, multi-domain student success analytics environment. The datasets represent academic performance, enrollment status, and learning management system (LMS) engagement signals commonly used in institutional retention analysis.

The sources are intentionally heterogeneous to reflect real-world data fragmentation across institutional systems.

---

## 1. Open University Learning Analytics Dataset (OULAD)

**Source:**  
https://analyse.kmi.open.ac.uk/open-dataset#data

The OULAD dataset provides detailed student engagement, assessment, and course interaction data from the UK Open University. It closely mirrors modern LMS and student information system (SIS) structures and serves as the primary source for behavioral and academic signals.

### Data description
Data description available at https://analyse.kmi.open.ac.uk/open-dataset#description

---

## 2. UCI Student Performance Dataset

**Source:**  
https://archive.ics.uci.edu/dataset/320/student+performance

The UCI Student Performance dataset provides structured academic performance and behavioral indicators from secondary education settings. While simpler than OULAD, it complements the platform by introducing standardized academic and behavioral covariates commonly found in student success models.

### Data description
Data description available at https://archive.ics.uci.edu/dataset/320/student+performance
